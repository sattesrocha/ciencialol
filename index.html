Ciência LOL

A private build roulette for a group of three League of Legends friends.

Private alpha · Windows

What it is

Ciência LOL is a small Windows desktop app (Go + WebView2) used only by three friends who play League of Legends together in Brazil. In Brazilian League slang a ciência is an off-meta build: an unusual mix of runes and items for a champion, played for fun.

Before we queue, the app randomly assigns one of these builds to each of us by role (Top, Jungle, Mid, ADC, Support). Each build lists its runes, summoner spells, skill order and item order. We can also write our own builds, like or comment on them, and track wins and losses inside our group.

The app is not public, not sold, has no ads, and has no accounts or servers of its own. It is shared directly between the three of us.

How it would use the League Client API

We want one convenience feature: an Import to League button that sets up the assigned build in the League Client, the same way popular companion apps import rune pages. It talks only to the client running on the same PC, using the local port and password from the client's lockfile, and only before the game starts.

EndpointWhy
GET /lol-summoner/v1/current-summonerIdentify the logged-in player (needed to save the item set).
GET /lol-champ-select/v1/sessionSee which champion the player locked in.
GET POST PUT DELETE /lol-perks/v1/pagesCreate or replace one rune page named "Ciencia LOL" with the assigned build. Other rune pages are never touched.
PUT /lol-perks/v1/currentpageSelect that rune page.
PATCH /lol-champ-select/v1/session/my-selectionSet the two summoner spells of the assigned build.
PUT /lol-item-sets/v1/item-sets/{summonerId}/setsSave the build's recommended items as an item set for that champion.

Rune, item, spell and champion names and icons come from Data Dragon. We do not use the Riot Web API at this time; if we add something later, we will update this registration first.

How the import works

  1. The player gets a build from the roulette and opens it.
  2. In champion select, the player clicks Import to League.
  3. The app writes the rune page, the two summoner spells and the item set, exactly as the player could do by hand in the client.
  4. Nothing else happens. Once the game starts, the app does not interact with League at all.

It does

  • Set one rune page, two summoner spells and one item set before the match
  • Act only when the player clicks a button
  • Run locally, on the player's own PC

It never

  • Reads game memory or modifies game files
  • Interacts with the game during a match
  • Automates any in-game action or shows live match information
  • Collects, stores or shares player data
