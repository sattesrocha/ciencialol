## Team roles
- **Committers and reviewers:** [Felipe Rocha (SattesRocha)](https://github.com/sattesrocha)
- **Approvers:** [Felipe Rocha (SattesRocha)](https://github.com/sattesrocha)

## What is signed
Only `CienciaLOL.exe` built by the GitHub Actions workflow in this repository
(`.github/workflows/build.yml`) from the public source code, for tagged releases.
Every release is approved manually before signing.

## Privacy policy
This program will not transfer any information to other networked systems unless
specifically requested by the user or the person installing or operating it.
See [PRIVACY.md](PRIVACY.md) for exactly which connections the app makes and when.
